한국어판 업데이트 — 2026-11-04

1. Unity 종료.
2. 새 ZIP 압축 해제.
3. 새 Assets 전체를 기존 프로젝트의 Assets와 합치고 같은 파일 덮어쓰기.
   기존 Assets를 삭제하지 마세요. Resources/Fonts 폴더도 함께 복사해야 합니다.
4. Unity 실행 후 기존 MainScene 열기.
5. Tools > Pixel Survivor > 한국어 적용 (Apply Korean) 실행.
6. Play > 시작 > 캐릭터 선택 > 다음: 스테이지 선택 > 전투 시작.

새 프로젝트는 Setup - Rebuild Game Scene으로 씬과 프리팹을 만듭니다.
저장 ID와 스탯은 유지되며 기존 영어 기본 이름/설명이 한국어로 바뀝니다.
실제 Unity 실행 검증은 아직 하지 못했습니다. 정적 검사 및 한글 폰트 검사 결과는 Documentation에 있습니다.
