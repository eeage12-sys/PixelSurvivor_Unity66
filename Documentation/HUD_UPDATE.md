# 전투 HUD / ESC 업데이트

2026-11-04. 기존 한국어판에 적용하는 변경입니다. 독립적인 아이콘/배치를 사용하며 참고 게임 이미지는 프로젝트에 포함하지 않습니다.

## 구현
- `CompactHUD.cs`: 화면 가장자리 앵커를 사용하는 EXP/LV, 단일 시간, 7+7 장비 아이콘, 아이콘 카운터, 발밑 HP. 카메라 추적 후 LateUpdate에서 월드 좌표를 화면으로 변환합니다.
- `GameUI.cs`: 캠페인의 기존 HUD 비활성화. 참조는 유지합니다. 편집 모드 메뉴의 비워진 라벨을 이름으로 복구합니다.
- `CampaignPauseUI.cs`: 기존 InputActionReference UI/Cancel(ESC)을 읽어 Playing/Paused 상태에서만 처리합니다. 정보/옵션/조합법 간 이동 중 전투를 계속 멈춥니다.
- `DisplayOptions.cs`: 피격 효과/발밑 체력바 설정을 별도 PlayerPrefs 키로 저장합니다. Windows 전체 화면은 옵션에서 즉시 전환합니다.
- `FitCanvasViewport.cs`: 좁은 화면은 너비, 넓은 화면은 높이를 기준으로 1600×900 기준 UI를 맞춥니다.
- `DestructibleProp.cs`, `PropHitEffect.cs`: 유효한 피해에만 반응. 짧은 밝기/크기 변화와 불꽃, 사망 시 파편. Time.deltaTime 사용으로 일시정지 시 함께 정지합니다.
- `KoreanSetup.cs`: 한국어 적용과 새 UI 업데이트 적용 메뉴에서 저장 씬 미리보기도 복구합니다.

상단 아이콘의 크기는 42×42, 간격 48(1600×900 기준). 발밑 HP는 48×7입니다. 숫자 HP는 ESC 정보창에 표시합니다.
장비 아이콘을 클릭해도 정보창이 열립니다. ESC 창에서 각 장비 데이터의 maxLevel만큼 칸을 만들고 현재 level만큼 밝힙니다.
조합법은 현재 8개 무기의 아이콘/조합 파트너/진화 결과와 보유 상태를 표시합니다.

## Unity 수동 검증 (미실행)
1. 기존 씬에 UI 업데이트 적용. 실행 전 제목/안내/버튼 글자가 보이는지 확인.
2. Play > 시작 > 캐릭터/스테이지 선택. 기존 위/아래 넓은 HUD가 안 보이고 새 HUD만 표시되는지 확인.
3. EXP 획득/레벨업 후 상단 바와 LV 표시 확인. 시간 한 개, 처치/골드 숫자 증가 확인.
4. 플레이어를 화면 중앙과 맵 가장자리로 이동. 피격/회복 후 발밑 HP 위치/비율 확인.
5. ESC로 정지: 몬스터/투사체/타이머가 멈추고 장비 두 줄과 레벨 칸 확인.
6. 옵션/조합법 이동 중 정지 유지. ESC로 정보창 복귀, 다시 ESC로 재개.
7. 레벨업/상자/사망 화면에서 ESC가 선택을 건너뛰지 않는지 확인.
8. 최대 레벨 장비, 최대 레벨 3인 강화형, 진화 장비의 칸 수/불빛 확인.
9. 사물에 공격: 반짝임/크기 반응/불꽃, 파괴 시 파편 확인. 옵션 끄면 효과가 중단되는지 확인.
10. 체력바 옵션을 끄고 켜기. 재시작 후 설정 유지, 전투 장비/카운터 초기화 확인.
11. Game 뷰 1920×1080, 1600×900, 4:3 및 자유 비율에서 잘림/겹침 확인.
12. Windows 빌드에서 전체 화면/창 모드 전환 확인.

## 검사 상태
정적 소스/에셋 검사만 실행했습니다. Unity Editor가 없는 환경이므로 실제 Unity 컴파일 및 위 체크는 NOT RUN입니다.
새 PlayMode 테스트 7개: 기존 HUD 숨김/단일 시계, ESC 정지·재개, 하위 메뉴 정지, 레벨 선택 보호, 레벨 칸, 발밑 추적/옵션, 사물 피격 효과.
기존 HUD 테스트도 새 바 이름/구조에 맞게 갱신했습니다. 실제 Test Runner 결과가 아닙니다.
