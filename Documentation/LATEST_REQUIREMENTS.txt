# Pixel Survivor 전체 시스템 최신 통합 기획 및 구현 요청서

현재 제작 중인 Unity 2D 탑다운 픽셀 로그라이트 게임 **Pixel Survivor**를 아래 최신 기획을 기준으로 수정 및 확장해 줘.

이 문서를 현재 프로젝트의 **최신 최종 기준 사양**으로 사용한다.

## 2026-11-10 확정 변경: 20분 종말의 추격자

- 한 Run의 목표는 20분 생존이다. 10분 보스는 기존처럼 등장한다.
- 20분 생존 시 다음 Stage를 해금하고, 기존 몬스터와 다른 전용 시계형 픽셀 아트의 종말의 추격자 한 마리가 등장한다. 20분 보스는 등장하지 않는다.
- 추격자는 무적이며 플레이어를 따라가 접촉하면 Run을 종료한다. 그동안 일반 몬스터는 사라진다.
- 빠른 테스트 또는 스테이지 체험 중에는 해금과 기록을 저장하지 않는다.
- 몬스터 피격 시 짧은 붉은 섬광과 시각적 흔들림, 플레이어 피격 시 작은 혈흔과 시각적 흔들림을 표시한다.
- 아래의 이전 무한 생존 및 20분 보스 처치 규칙과 충돌하면 이 변경을 우선한다.

이전 요청이나 기존 구현과 내용이 충돌할 경우 **반드시 이 문서의 내용을 우선한다.**

기존에 정상 작동하는 기능은 최대한 유지하고, 필요한 부분만 수정·교체·확장한다.

개발 환경:

- Unity 6.6 / 6000.6.6f1
- 2D
- Pixel Art
- Unity Input System 사용
- Windows PC 우선

# 3. 플레이어 조작

플레이어 이동은 키보드에서 **WASD와 방향키를 모두 지원한다.**

## WASD

W = 위

S = 아래

A = 왼쪽

D = 오른쪽

## 방향키

↑ = 위

↓ = 아래

← = 왼쪽

→ = 오른쪽

두 방식 모두 동일한 이동 기능을 제공한다.

---

# 4. Input System

Unity의 새로운 **Input System**을 사용한다.

Move Action 하나에 다음 Binding을 함께 등록한다.

WASD Composite

+

Arrow Key Composite

예:

Move

- W / A / S / D
- Up / Left / Down / Right Arrow

별도의 이동 스크립트를 두 개 만들지 않는다.

하나의 Move Action으로 두 조작 방식을 모두 처리한다.

---

# 5. 이동 관련 필수 규칙

대각선 이동 시 이동속도가 빨라지면 안 된다.

입력 Vector를 Normalize 또는 ClampMagnitude 처리한다.

예:

W + D

또는

↑ + →

입력 시에도 직선 이동과 동일한 최대 이동속도를 유지한다.

또한 WASD와 방향키를 동시에 눌렀다고 이동속도가 2배가 되면 안 된다.

예:

W + ↑

를 동시에 눌러도 위쪽 이동속도는 정상적인 기본 Move Speed여야 한다.

# 6. 기존 제한시간 시스템 폐기

현재 프로젝트에 존재하는 다음 시스템은 제거한다.

- A FIVE-MINUTE SURVIVAL RUN
- Survive for 05:00
- 5분 Victory
- Countdown Timer
- 시간 경과에 따른 자동 Victory

게임에는 기본적인 제한시간이 없다.

플레이어가 사망할 때까지 계속 플레이할 수 있어야 한다.

# 7. Survival Time

시간은 감소하지 않고 계속 증가한다.

UI 예:

SURVIVAL TIME

00:14:37

20분 생존 시 종말의 추격자가 등장한다. 추격자 접촉이 Run 종료 조건이다.

시간은 다음 시스템에 사용한다.

- Enemy Scaling
- Spawn Rate
- Spawn Count
- 새로운 Monster 등장
- Elite 출현
- Boss 등장
- Stage Unlock

---

# 8. Run 종료 조건

Run 종료 조건은:

## Player Death 또는 20분 이후 종말의 추격자 접촉

이다.

20분에 즉시 종료하지 않고 추격자를 등장시킨다. 추격자가 플레이어를 붙잡으면 종료한다.

# 10. Stage 시스템

Stage는 존재한다.

하지만 한 Run 안에서 Stage가 자동 전환되지 않는다.

각 Stage는 독립적인 Run이다.

예:

Stage 1

Stage 2

Stage 3

각 Stage는:

- Map
- Monster
- Difficulty
- Boss
- Spawn Table

등을 다르게 구성할 수 있다.

---

# 11. Stage Unlock

처음에는 Stage 1만 사용 가능하다.

Stage 1에서:

20:00 생존 달성

↓

종말의 추격자 등장

↓

STAGE 2 UNLOCKED

Stage 2가 해금된다.

현재 Stage 1 Run은 추격자에게 붙잡힐 때까지 이어진다.

Player Death 후 Main Menu로 돌아오면 Stage 2 선택이 가능하다.

Unlock 상태는 영구 저장한다.

# 26. 기존 단순 스탯 선택지 폐기

다음과 같은 선택지는 직접 등장하면 안 된다.

- Damage +20%
- Move Speed +10%
- Attack Speed +15%

이런 기존 스탯 Upgrade 선택 시스템은 제거한다.

---

# 27. 스탯 효과는 강화형 장비

예:

Damage +10%

이라는 선택지를 직접 보여주는 것이 아니라:

## 공격 강화 장비 Lv.1

Damage +10%

형태로 등장한다.

---

# 28. 장비 종류

전투 중 장비는 크게 두 가지다.

## A. 공격형 장비

직접 Monster에게 Damage를 준다.

## B. 강화형 장비

직접 공격하지 않고 Character 또는 공격형 장비를 강화한다.

---

# 29. 장비 Slot

한 Run에서:

## 공격형 장비 최대 7개

## 강화형 장비 최대 7개

총 최대 14 Slot.

전체 게임에 존재하는 장비 종류는 7개보다 많아도 된다.

# 34. 강화형 장비 예시

- Damage 증가
- Attack Speed 증가

# 35. 강화형 장비 Level

강화형 장비도 Level을 가질 수 있다.

동일 강화형을 다시 선택하면 기존 강화형 Level +1.

새 Slot을 사용하지 않는다.

---

# 36. 강화형 장비 진화 금지

## 강화형 장비는 절대 진화하지 않는다.

강화형 → 상위 강화형 같은 시스템을 만들지 않는다.

---

# 37. 강화형 장비 역할

강화형 장비 역할:

1. Player 및 공격형 장비 성능 강화
2. 공격형 장비 Evolution 조건

---

# 38. 공격형 Evolution

Evolution 가능한 것은 **공격형 장비뿐**이다.

반드시 두 조건을 모두 만족해야 한다.

## 조건 1

공격형 장비 MAX Level

## 조건 2

해당 공격형 장비와 연결된 특정 강화형 장비 보유

# 44. Evolution 상태

공격형 Level 부족 + 강화형 없음

→ 미충족

공격형 Level 부족 + 강화형 있음

→ Weapon Level 부족

공격형 MAX + 강화형 없음

→ Enhancement 필요

공격형 MAX + 강화형 있음

→ EVOLUTION READY

# 50. Elite Treasure Chest

# 51. Treasure Chest Evolution Check

Chest를 열면 우선:

Weapon MAX?

+

Required Enhancement 보유?

를 체크한다.

YES면 해당 Weapon을 Evolution Candidate에 등록한다.

---

# 52. Elite Chest Jackpot

Elite Chest는 기본 1회 보상이다.

하지만 일정 확률로:

3개 Jackpot

또는

5개 Jackpot

가능.

초기 예시:

1회 = 85%

3회 = 12%

5회 = 3%

데이터에서 수정 가능.

---

# 53. Jackpot 예시

5회 Jackpot:

1. Whip Evolution
2. Dagger Lv.2 → Lv.3
3. Damage Enhancement Lv.1 → Lv.2
4. Magic Orb Lv.4 → MAX
5. Area Enhancement Lv.2 → Lv.3

Evolution도 1회 보상으로 계산한다.

---

# 54. 모든 장비 MAX

더 이상 강화 또는 Evolution 가능한 장비가 없다면 Chest 보상을 Gold로 변환한다.

Jackpot 중 강화 대상이 사라지면 남은 보상도 Gold로 변환한다.

---

# 55. Boss Treasure Chest

Boss Kill 시 Boss Chest를 100% Drop한다.

Boss Chest는:

## 랜덤 장비 보상 3회 확정

이다.

---

# 56. Boss Chest 결과

각 보상은 다음 중 하나가 될 수 있다.

- 공격형 +1 Level
- 강화형 +1 Level
- Evolution
- 강화 대상 없음 → Gold

---

# 57. Elite와 Boss Chest 차이

Elite:

기본 1회.

3회 / 5회 Jackpot 확률 존재.

Boss:

# 86. 절대 변경하지 말아야 할 최종 확정 규칙

1. 게임은 20분 생존 도전 방식이다.

2. 20분에 무적 추격자가 등장하고, 추격자 접촉으로 Run을 종료한다.

3. 20분 이전에는 Player Death, 이후에는 무적 추격자 접촉이 Run 종료 조건이다.

4. WASD로 Player 이동 가능해야 한다.

5. 방향키로도 Player 이동 가능해야 한다.

6. WASD와 방향키 모두 동일한 Move Action을 사용한다.

7. 대각선 이동속도가 빨라지면 안 된다.

8. WASD와 방향키를 동시에 눌러도 이동속도가 중첩되면 안 된다.

9. Boss는 10분에 등장한다.

10. 20분 생존 시 다음 Stage를 Unlock한다.

11. Stage Unlock 이후 추격자에게 붙잡힐 때까지 현재 Run을 계속한다.

12. Character는 초기 5명이다.

13. Character Select를 반드시 구현한다.

14. Stage Select를 반드시 구현한다.

15. Level Up 선택지는 장비 기반이다.

16. 단순 스탯 증가 선택지는 사용하지 않는다.

17. 스탯 효과는 강화형 장비 형태로 제공한다.

18. 공격형 장비 최대 보유량은 7개다.

19. 강화형 장비 최대 보유량은 7개다.

20. 공격형 장비만 Evolution 가능하다.

21. 강화형 장비는 Evolution하지 않는다.

22. 공격형 장비가 MAX가 아니면 Evolution할 수 없다.

23. 공격형 MAX + 특정 강화형 보유 조건이 모두 필요하다.

24. 조건을 만족해도 즉시 Evolution하지 않는다.

25. Treasure Chest를 통해 Evolution한다.

26. 공격형 Evolution 시 강화형 장비는 소모되지 않는다.

27. 공격형 카드에 필요한 강화형 장비를 UI로 표시한다.

28. 강화형 카드에 관련 Weapon Synergy를 표시한다.

29. Elite는 일반 Monster와 색상이 달라야 한다.

30. Elite Kill 시 Treasure Chest 100% Drop.

31. Elite Chest는 기본 1회 강화.

32. Elite Chest는 3회 / 5회 Jackpot 가능.

33. Boss Kill 시 Boss Chest 100% Drop.

34. Boss Chest는 장비 보상 3회 확정.

35. 모든 장비 MAX 시 Chest 보상은 Gold로 전환한다.

36. Field Breakable Object가 존재한다.

37. Gold Drop이 존재한다.

38. Magnet이 존재한다.

39. Bomb이 존재한다.

40. Heal이 존재한다.

41. Support Call이 존재한다.

42. Support Call은 공격 / 회복 / 방어 중 Random이다.

43. Support Unit은 장비 Slot을 사용하지 않는다.

44. Run 장비는 Run 종료 시 초기화한다.

45. Gold는 영구 유지한다.

46. Common Upgrade는 영구 유지한다.

47. Character Unique Upgrade는 영구 유지한다.

48. Stage Unlock은 영구 유지한다.

49. Best Survival Time을 저장한다.

# 최종 목표

Pixel Survivor를 단순한 5분 생존 프로토타입이 아니라,

**WASD와 방향키로 5명의 캐릭터 중 하나를 조작하며 장비를 조합·진화시키고, 10분 보스를 거쳐 20분 생존으로 다음 Stage를 해금하는 2D 픽셀 로그라이트 RPG. 20분에는 고유한 무적 추격자가 등장하며, 붙잡히면 Run이 끝난다.**

로 완성하는 것이 최종 목표다.

**이 문서를 최신 최종 사양으로 사용하고, 이전 구현이나 이전 요청과 충돌하는 내용이 있다면 반드시 이 문서의 내용을 우선한다.**
